关于建立这个博客的初心

高中的一时兴起

顺利考上高中后，在父母的支持下，我买了一台配置不算高、但也绝对不低的台式电脑：i3-10100、8GB DDR4 内存、512GB NVMe 固态硬盘，以及 UHD630 核显。相比之下，那台老旧的 ThinkCentre 在我心中的地位也渐渐下降了几分。 也正是从那时候开始，我第一次真正接触并探索 Linux 的世界。 刚接触这些东西时，一切都显得陌生又新奇。搜索引擎成了最好的老师，我开始在互联网上查阅各种文档与教程。而在这些教程中，有相当一部分都来自各种个人博客。 也是从那时起，我第一次真正意识到：“原来互联网里，还可以有属于自己的一片空间。” 漂亮的鼠标点击动画、风格各异的背景、清晰的文章目录……这些东西深深吸引了我。博客不仅仅是记录技术与生活的工具，它更像是一种“个人存在感”的延伸。 那时的我，也开始萌生出：“以后自己也要搭建一个博客”的想法。 我曾经看过不少搭建博客的教程，最早接触到的是 Termux + Hexo 的方案。那时候还不知道 GitHub Pages 这种方便又免费的服务，大多数教程仍然需要购买服务器和域名。 但由于高中学业压力，以及经济条件上的限制，这个想法最终还是被搁置了。

大学生活的丰富多彩

时间转眼来到大学。相比高中，大学的生活明显自由了许多。人也终于有了更多可以自由支配的时间，去尝试自己真正感兴趣的事情。 于是，“搭建个人博客”这个曾经一闪而过的念头，又重新浮现在我的脑海中。 在大一上学期时，我第一次认真尝试搭建博客： 1. 安装 Node.js 2. 配置 npm 3. 安装 Hexo 4. 克隆主题 5. 修改配置…… 当我第一次在浏览器中打开 localhost:4000，看到属于自己的页面成功显示出来时，那种感觉其实挺奇妙的。可惜的是，当时恰好临近期末，博客也只能暂时搁置。 直到今天，在 GitHub Pages、ChatGPT，以及各种官方文档的帮助下，我终于真正搭建起了属于自己的个人博客。

为什么搭建这个博客

正如前面所说，在浏览过许多大佬的个人博客后，我逐渐发现：博客真正吸引人的，并不只是炫酷的动画与页面设计。更重要的是：这里记录着一个人的经历、思考、热爱与成长。 一个博客，就像互联网中的私人角落。你可以在这里：

  • 记录学习过程
  • 分享生活中的琐事
  • 写下对作品的感受
  • 留下某个阶段的思考
    而这些东西，都会随着时间慢慢沉淀下来。所以，我也希望能把自己学到的东西、想到的事情、对生活的感受，一点点写进这里。 也希望这次的热情，不会再像以前那样，只停留“三分钟热度”。 （笑）
