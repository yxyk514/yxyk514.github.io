关于建这个博客的初心
发表于2026-05-13
关于建立这个博客的初心高中的一时兴起顺利考上高中后，在父母的支持下，我买了一台配置不算高、但也绝对不低的台式电脑：i3-10100、8GB DDR4 内存、512GB NVMe 固态硬盘，以及 UHD630 核显。相比之下，那台老旧的 ThinkCentre 在我心中的地位也渐渐下降了几分。 也正是从那时候开始，我第一次真正接触并探索 Linux 的世界。 刚接触这些东西时，一切都显得陌生又新奇。搜索引擎成了最好的老师，我开始在互联网上查阅各种文档与教程。而在这些教程中，有相当一部分都来自各种个人博客。 也是从那时起，我第一次真正意识到：“原来互联网里，还可以有属于自己的一片空间。” 漂亮的鼠标点击动画、风格各异的背景、清晰的文章目录……这些东西深深吸引了我。博客不仅仅是记录技术与生活的工具，它更像是一种“个人存在感”的延伸。 那时的我，也开始萌生出：“以后自己也要搭建一个博客”的想法。 我曾经看过不少搭建博客的教程，最早接触到的是 Termux + Hexo 的方案。那时候还不知道 GitHub Pages 这种方便又免费的服务，大多数教程仍然需要购买服务器和域名。 但由于高中...
